# 鹿功汇平台(Django 版)

> 传承武学 · 修习身心

鹿功汇是一个武学文化传承与学习平台,致力于通过数字化方式传播传统武术文化。本仓库是对原 [腾讯云 CloudBase 全栈版本](https://cnb.cool/zhanxiaoyu/wuxue) 的完整重写:所有代码基于 **Python Django** 框架重新实现,使用服务端渲染模板替代 Vue 前端,使用 Django ORM + 关系型数据库替代 CloudBase 云函数 + NoSQL。

## 功能总览

### H5 移动端(用户端,路径 `/`)

- **登录注册**:手机号 + 短信验证码,一步登录/注册,支持邀请码奖励(邀请人 +50 积分,新用户注册 +100 积分)
- **首页**:武学传承 / 武学短剧 短视频 feed,支持频道筛选与点赞
- **武学课堂**:课程列表(分类筛选 + 关键词搜索 + 分页)、课程详情与章节目录、积分报名修习
- **文章资讯**:武学图文列表与详情(支持公众号原文链接)
- **报单**:提交课程咨询/私教指导等报单,查看审核进度
- **积分中心**:积分余额与流水、积分兑换商品 / VIP 会员(兑换 VIP 立即生效)
- **消息中心**:系统/课程/报单/积分通知,点击标记已读
- **个人中心**:修习档案、报名记录、邀请码、资料编辑

### 管理后台(运营端,路径 `/admin/`)

- **数据看板**:核心指标卡片(用户/积分/待审报单/VIP/课程/报名)、近 30 天用户增长曲线、报单状态分布、课程热度 Top 10、待办事项
- **用户管理**:列表筛选、详情(基本信息/积分/VIP/关联数据)、编辑角色与状态、VIP 手动开通/续期/取消
- **积分管理**:积分发放/扣减(自动写流水 + 通知 + 日志)、流水查询、兑换记录处理(取消自动退积分)
- **报单管理**:列表筛选、详情、审核通过/拒绝(拒绝必填备注,自动通知用户)
- **课程管理**:课程 CRUD、一键上下架、章节管理
- **服务管理**:服务套餐 CRUD
- **内容管理**:文章 CRUD、首页 feed 视频 CRUD
- **消息管理**:消息查询、发送/群发(指定用户 / 全部 / VIP / 普通用户)
- **兑换目录**:积分兑换商品 CRUD(含 VIP 商品配置)
- **操作日志**:所有管理操作自动审计(操作者/模块/动作/目标/IP)

### 角色与权限

| 角色 | 说明 | 后台权限 |
|------|------|---------|
| 超级管理员 `super_admin` | 拥有全部权限 | 全部,含修改用户角色 |
| 运营管理员 `admin` | 日常运营 | 除修改角色/系统设置外的全部 |
| 咨询师 `consultant` | 审核报单 | 报单审核、查看客户、查看自己的日志 |
| 会员 / 普通学员 | 前端用户 | 不可登录后台 |

## 技术栈

- **后端**:Python 3.10+ / Django 5+
- **数据库**:SQLite(开发默认),可通过 `DATABASES` 配置切换 PostgreSQL/MySQL
- **前端**:Django 模板 + 原生 CSS/JS(移动端适配,无外部前端依赖)
- **认证**:自定义 User 模型(手机号为凭证),H5 验证码登录 + 后台密码登录

## 快速开始

```bash
# 1. 安装依赖(建议使用虚拟环境)
pip install -r requirements.txt

# 2. 初始化数据库
python manage.py migrate

# 3. 初始化演示数据(管理员、课程、文章、视频、兑换商品)
python manage.py seed_demo

# 4. 启动开发服务器
python manage.py runserver
```

访问:

- H5 移动端:<http://127.0.0.1:8000/>
- 管理后台:<http://127.0.0.1:8000/admin/>
- Django 原生 Admin:<http://127.0.0.1:8000/django-admin/>

## 业务规则

- **积分守恒**:所有积分变动通过 `apps/points/services.py::change_points` 原子完成,自动校验余额、写入流水(`PointLedger`)并更新历史累计
- **积分兑换比例**:100 积分 = 1 元(`settings.POINTS_PER_YUAN`)
- **VIP 兑换**:1000 积分兑换 30 天 VIP,未过期续兑自动累加
- **审计**:所有后台写操作通过 `log_admin_action` 记录到 `AdminLog`
- **通知**:积分变动、报单审核、课程报名、VIP 变更均自动发送站内消息

## 生产部署提示

- 设置环境变量 `DJANGO_SECRET_KEY`、`DJANGO_DEBUG=0`、`DJANGO_ALLOWED_HOSTS`
- 短信验证码目前在生产模式下生成随机码但未接入短信服务商,需在 `apps/h5/views.py::send_code` 中接入真实短信 API
- 使用 `python manage.py collectstatic` 收集静态文件,并配置 WSGI 服务器(如 gunicorn)与反向代理
